# Portfolio – Nguyễn Phú Hưng

Trang giới thiệu bản thân và các dự án, chạy trên GitHub Pages: https://phuhung2805.github.io

- Trang tĩnh một file (`index.html`), không cần build.
- Danh sách dự án nằm trong mảng `projects` ở cuối `index.html`. Muốn thêm dự án, chép một mục rồi sửa lại.
- Ảnh minh họa đặt trong `assets/img/`.

## Xem trên máy

```bash
python -m http.server 8000
```

Sau đó mở http://localhost:8000
